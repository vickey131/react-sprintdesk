# SprintDesk release notes

## Current release

SprintDesk lets manage tasks on a single sprint board.

- Create and edit tasks with a title, description, due date, priority, and status.
- Search by title or description, filter by status or priority, and hide completed tasks. Search and filters can be shared in the URL.
- Sort by priority or newest first.
- Track task counts by status and see which high-priority tasks are still open.
- Update task status, or delete a task after confirming the change.
- See loading and error messages, retry failed requests, and keep form entries when a save fails.
- Try the performace with 500 sample tasks.

During local development, an MSW mock API serves sample tasks in memory. Changes are not stored in a production backend.
